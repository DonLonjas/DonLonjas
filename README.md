## Proyectos
- **[Albion Master](https://albionmaster.site/)** — Bot de Discord para Albion Online: eventos y splits de silver, canales de voz temporales, scout de recursos con 278 mapas, mercado por IA (beta), licencias y panel. 37 comandos en ES/EN.
- **[Bot de eventos de Discord](https://github.com/DonLonjas/Bot-Eventos-Discord)** — Gestión de eventos, economía, distribución automática de ganancias, multi-servidor con datos independientes, comandos en ES/EN/PT. MIT.
- **[Monitor](https://github.com/DonLonjas/Monitor)** · [Demo](https://monitor.andreslancheros.dev/) — Dashboard de métricas de sistema: Express recoge CPU, RAM, discos, red y GPU con `systeminformation` y los expone via API JSON.
- **[Guía de desarrollo básico](https://github.com/DonLonjas/guia-desarrollo-basico)** · [Demo](https://guia.andreslancheros.dev/) — Sitio interactivo para aprender HTML, CSS, JavaScript, Node.js, Express, SQL y MongoDB.
- **[Sameron Pizza](https://sameronpizza.vercel.app/)** — Web para una pizzería de Yopal: catálogo y pedidos en línea. React + Vite.
